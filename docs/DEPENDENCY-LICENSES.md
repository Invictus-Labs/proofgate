# Dependency license audit

Generated by `node scripts/dependency-licenses.mjs` from `package-lock.json` and each installed package's own
`package.json`. Policy: permissive licenses only (MIT, ISC, BSD, Apache-2.0 and similar). ProofGate itself is
MIT (see `LICENSE`; the README's "License decision" note records why: the same license and holder as the
sibling public projects RunProof and ScopeGuard, plus this audit).

Direct runtime dependencies (pinned exactly): yaml@2.9.1, zod@4.6.5.
Direct development dependencies: @playwright/test@1.63.0, @types/node@26.6.3, @vitest/coverage-v8@5.0.2, ajv@8.20.0, typescript@7.0.2, vitest@5.0.2.

Result: **all packages carry an allowed permissive license**.
Reviewed exception: 12 development-only packages are MPL-2.0 (lightningcss, pulled in by vitest through vite). MPL-2.0 is file-level weak copyleft; these packages are unmodified, used only to run tests and never shipped or linked into ProofGate, so no MPL obligation attaches to ProofGate itself. No runtime dependency is outside the permissive list.

Runtime packages: 2. Development-only packages: 103. Development-only packages are not shipped
(`package.json` `files` publishes only `dist`, `schemas`, `fixtures`, selected docs and the license; the packaged-executable
test asserts that no source, test or tooling file is in the tarball).

Non-npm test tooling: the browser smoke uses Playwright (Apache-2.0), which downloads a Chromium build on demand
(`npx playwright install chromium`). That browser is used only to run tests on a developer's machine; it is not an npm
dependency, is never vendored, committed or shipped, and is therefore outside this npm audit.
