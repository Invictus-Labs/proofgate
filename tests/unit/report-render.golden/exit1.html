How to read the statuses

Only PASS satisfies a requirement. Every other status, including DEFERRED, is visible and keeps a mandatory requirement from being accepted.

✓ PASS
Every required repository has fresh, complete, passing evidence for the exact revision, environment and test level. Satisfies the requirement.
✗ FAIL
Fresh evidence for the exact revision contains a failing test or contradicts itself. Not satisfied. A failing mandatory requirement blocks acceptance.
◷ STALE
The only matching evidence is at or beyond the maximum allowed age. Evidence exactly at the limit is already stale. Not satisfied. Old evidence is not accepted.
○ MISSING
No matching evidence exists, or the only evidence is passing claims of runs that executed zero tests. Not satisfied. Absence of evidence is not a pass.
◐ PARTIAL
The evidence is incomplete: skipped tests, a partial result, or only some of the declared repositories are covered. Not satisfied. Incomplete evidence is not accepted.
◇ DEFERRED
The manifest explicitly defers this requirement. It is unverified and stays visible. Not satisfied. Deferral never satisfies a mandatory requirement.

Generated statically from report.json: no script runs, nothing is fetched, no artifact link is followed. ProofGate verifies that receipts are consistent with the declared policy and revisions; it does not prove that the party that produced a receipt was honest.
