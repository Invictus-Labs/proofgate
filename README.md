# ProofGate

Self-hosted acceptance gate: prove which requirements passed, on which exact revisions, with fresh verifiable evidence.

**Status: pre-MVP, under development.** Nothing in this repository is a release. The product contract is [docs/prd/proofgate.md](docs/prd/proofgate.md).

- License: MIT
- Runtime: Node.js 22+ and TypeScript CLI with a static HTML report (no database, no daemon)
- Standalone: no account, license server, telemetry or paid provider is required.

This README is replaced with installation and operator documentation as the MVP lands.
